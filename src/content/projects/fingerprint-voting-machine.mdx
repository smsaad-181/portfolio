## Overview

A standalone biometric voting system on a custom PCB: one finger, one vote, with live results over Wi-Fi. Each voter is identified by an R503 capacitive fingerprint sensor, and a matched voter who has not yet voted gets a 15-second window to press one of four candidate buttons. The vote is stored on the device and the voter is flagged, so a second attempt is rejected.

The ESP32 runs everything itself, with no server, cloud service or phone app. It joins the local Wi-Fi network and serves a web dashboard where the administrator enrolls voters, watches live results, exports a CSV log and resets the election.

## Features

- Fingerprint match opens a 15-second vote window; if no button is pressed, no vote is counted and the voter is not marked as voted, so they can scan again.
- Rejected scans (unknown finger or already voted) return the machine to idle; candidate buttons are ignored outside the vote window.
- Matching uses `fingerSearch(1)` first with `fingerFastSearch()` as a fallback, at a configurable match security level.
- Dashboard-only enrollment: two scans per finger, with a duplicate search on the first scan that aborts if the fingerprint is already enrolled.
- Fingerprint templates (up to 200) live in the R503 flash; voter profiles, voted flags and vote totals live in ESP32 NVS and survive power loss.
- Embedded single-page dashboard on port 80 with live results, CSV export of the event log and election reset; a standalone HTML preview runs the same dashboard on simulated data.
- Voting keeps working offline when Wi-Fi is unavailable.
- Firmware runs as one cooperative loop that is always in one of three modes: idle scan, enrolling or vote window.
