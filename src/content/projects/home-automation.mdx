## Overview

These boards bring Wi-Fi and wall-switch control to household mains loads such as lights, fans and sockets. Each one is a through-hole PCB built around an ESP32 module that runs a self-hosted web server, so it needs no cloud service, smartphone app or subscription: only the local Wi-Fi network and a browser.

The design exists in three revisions: a 4-channel board (V1) and two 6-channel boards (V2.1 and V2.2). All three share the same core: an onboard AC-DC supply, an isolated relay drive per channel, physical switch inputs and USB-C programming.

## Features

- 4 or 6 independent relay channels, driven active-high (GPIO HIGH turns the relay on).
- Each channel combines a PC817C optocoupler, a 2N2222A driver, a 1N4007 flyback diode and a status LED.
- Onboard Hi-Link AC-DC module powers the board straight from 220 V mains, with no external adapter.
- One physical wall-switch input per relay; firmware debounces each input over 50 ms.
- Self-hosted web dashboard on port 80 with a card-based UI that refreshes every 3 s.
- Per-relay custom names, daily ON/OFF schedules synced over NTP and a countdown auto-off timer.
- Per-relay statistics (trigger count, total ON time, last ON/OFF) and a 10-entry event log, all stored in ESP32 NVS flash.
- Master All-ON, All-OFF and Restart controls, plus a KPI row showing relays on, device IP, Wi-Fi RSSI and uptime.
- Wi-Fi credentials entered once over the serial monitor and saved to NVS; static IP by default with DHCP fallback.
- MOV surge suppression on the mains input and ESD protection on USB (V1 and V2.2).
