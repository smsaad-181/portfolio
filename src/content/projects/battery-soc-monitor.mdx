## Objective

A compact, low-power IoT node for monitoring a Li-ion battery. It measures the cell's terminal voltage, derives the state of charge (SoC) and uploads both values to ThingSpeak over Wi-Fi. Between measurements the ESP32 sits in deep sleep to keep current draw low, which suits battery-powered field deployments.

The hardware is a purpose-designed PCB with USB-C power input, onboard regulation, decoupling, a status LED, I²C and GPIO expansion headers and a dedicated UART programming header.

| TI BQ24092DGQR | U3 | Single-cell Li-ion charger |
| TI TPS63020DSJT | U2 | Buck-boost regulator for the 3.3 V rail |
| Coilcraft XFL4020-152MEC, 1.5 µH | L1 | Power inductor for the buck-boost converter |

| PZ254V-11-06P 6-pin header | H1 | UART programming header (GND, RTS, 3V3, RXD, TXD, DTR) |

## Features

- Battery voltage measured on IO34 (ADC1_CH6) through a 100 kΩ / 100 kΩ divider that halves the cell voltage.
- 32 times oversampling with the eFuse-calibrated `analogReadMilliVolts()`, plus an optional piecewise ADC calibration table and a global offset.
- SoC from piecewise-linear interpolation of a 21-point Li-ion open-circuit-voltage curve, clamped to 1–100 % before upload.
- ThingSpeak upload over HTTP: field 1 is battery voltage (V), field 2 is SoC (%).
- ESP32 deep sleep with a 30 s timer wake-up (configurable), safely above ThingSpeak's 15 s minimum update interval.
- Wi-Fi connection retried up to 5 times at 1 s intervals; on failure the node skips the upload and sleeps again instead of hanging.
- Wi-Fi and Bluetooth shut down before every sleep.
- UART programming header with RTS and DTR for auto-reset, I²C header and GPIO breakouts (IO34, IO35, IO27, IO26, IO25, IO18, IO5, IO14, IO13, IO2).

## Hardware Design

### Battery sense

The cell connects through a 100 kΩ / 100 kΩ divider, so the ADC pin sees half the battery voltage. With the ADC set to 11 dB attenuation the pin can read up to about 3.9 V, which keeps a fully charged 4.2 V cell (2.1 V at the pin) well inside the range. IO34 is an input-only pin on ADC1 (channel 6).

### Power

USB-C is the power input. The BOM fits a BQ24092 single-cell charger and a TPS63020 buck-boost converter with a 1.5 µH Coilcraft inductor for the 3.3 V rail, and a resettable PTC fuse.

### Programming and expansion

A 6-pin header carries GND, RTS, 3V3, RXD, TXD and DTR for an external USB-to-UART adapter, with RTS and DTR available for automatic reset. A 4-pin I²C header (SDA, SCL, 3V3, GND) and several GPIO breakout connectors expose spare pins for additional sensors.

### Firmware cycle

Each wake-up follows the same sequence: sample the ADC, convert voltage to SoC, connect to Wi-Fi, post to ThingSpeak, switch the radios off, and return to deep sleep. The battery is measured before Wi-Fi starts to keep the awake time short.

## Outcome

The GitHub repository holds the full package: schematic PDF, editable EasyEDA project, Gerber files, BOM, pick-and-place file, 3D STEP model, a project documentation PDF and the Arduino firmware (`SoC.ino`).

The firmware implements the complete wake, measure, upload and sleep cycle. The SoC estimate depends only on voltage: the OCV table describes a typical single cell at about 25 °C, and the ADC calibration table ships as an identity mapping for the user to fill in with multimeter readings. No measured accuracy or battery-life results are documented yet.
