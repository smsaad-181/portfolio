## Overview

Simon is a classic electronic memory game: the board flashes a sequence of coloured LEDs with matching tones, and the player repeats it on the buttons. Each successful round adds one step, and a wrong press resets the game.

This project turns the game into a single custom PCB shaped like a game controller. An ESP32 module handles game logic, display output and audio, a 0.96-inch OLED shows score and status, and a battery connector allows portable play. The board went through two revisions, V1.0 and V1.2.

## Features

- Custom game-controller-shaped 2-layer PCB outline.
- ESP32 module with Wi-Fi and Bluetooth on board.
- 0.96-inch I²C OLED for score and sequence feedback (SDA on IO21, SCL on IO22 in V1.0).
- Four LEDs for the colour sequence and four Omron B3F-4055 12 mm tactile keys for player input.
- 2.7 kHz buzzer for tones and error feedback.
- Onboard CH340C USB-to-UART, so the board flashes over USB without an external adapter.
- 2-pin battery connector for portable use.
- Breakout headers: V1.0 has an 8-pin header with UART, input pins and 3V3; V1.2 has a 4-pin 3V3, GND, RX, TX programming header.
