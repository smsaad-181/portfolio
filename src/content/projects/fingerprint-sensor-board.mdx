## Overview

The Fingerprint Sensor Board is a carrier PCB for an Ai-Thinker ESP32-S module. It brings together the connectors needed for a fingerprint sensor, an RFID reader and a small display on one board, with USB-C programming and a 5 V supply built in.

It exists in two versions with the same parts list: V1.1 on a square board, and V1.2 on a reshaped L-shaped board with an extra mounting hole. The Versions section above compares them.

## Features

- Ai-Thinker ESP32-S module as the controller
- USB-C programming through a CH340C bridge, with BC847 transistors for automatic reset and boot entry, plus manual BOOT and RST buttons
- USBLC6-2SC6 ESD protection on the USB connection
- 5 V DC jack input with an AMS1117-3.3V regulator for the 3.3 V rail
- Headers for a fingerprint sensor (3V3, GND, TX, RX), an RFID reader (SDA, SCK, MOSI, MISO, GND, RST, 3V3) and a display (LED, SCK, SDA, A0, RST, CS, GND, 3V3)
- 12 mm OMRON push button and a status LED for user interaction
- Test points TP1 and TP2 (V1.1) and M3 mounting holes on both versions
