## Motivation

A self-contained game PCB as a platform for practicing ESP32-based firmware design — state machines, debouncing, tone generation — all in a form factor that's actually fun to use.

## Key Components

- **ESP32** — manages game state, button polling with debounce, LED sequencing, and buzzer tones
- **SSD1306 OLED** — shows current level, score, and game-over screen
- **4× colored LEDs + 4× tactile buttons** — the core Simon interaction
- **Passive buzzer** — distinct tone per button; rising pitch sequence on level advance

## Outcome

Fully playable game with increasing sequence length per level, high-score tracking in firmware, and distinct audio feedback per input. A compact, standalone PCB with no external dependencies.
