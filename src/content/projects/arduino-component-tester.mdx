## Motivation

A bench utility for identifying and characterizing unknown components (resistors, capacitors, diodes, transistors, MOSFETs). Rather than buying one off the shelf, building it from the open-source Kubbeler tester codebase was an opportunity to understand the measurement math, not just use the tool.

## Key Components

- **Arduino (ATmega328P)** — handles measurement cycles and OLED communication
- **SSD1306 128×64 OLED** — I²C display for component type and measured values
- **ZIF socket** — zero-insertion-force socket for connecting components under test safely

## Challenges & How They Were Solved

**Display output rendering in wrong color zone** — The SSD1306 used has a dual-zone panel (yellow strip at the top, blue below). The initial firmware was drawing text in the yellow strip but the SSD1306 library's coordinate system mapped that area to row 0; adjusting the y-offset by 16 pixels moved all output into the readable blue zone.

**Understanding the measurement algorithm** — The Kubbeler tester uses a charge/discharge technique to measure component characteristics without dedicated ADC hardware beyond the ATmega's built-in ADC. Studied the source math for transistor hFE measurement and capacitor ESR estimation before making any firmware modifications.

## Outcome

Functional component tester producing accurate readings for resistors, capacitors, and BJTs. Used regularly as a bench tool for incoming component checks.
