## Part B — Target state (definition of "professional")

A recruiter landing on the site should, within 10 seconds, see:

1. **Who:** name, the title "Hardware Engineer", employer and location.
2. **What:** one positioning line, e.g. *"I design PCBs and embedded firmware for IoT products — ESP32, LoRaWAN, Modbus — from schematic to working board."*
3. **Proof:** 3 featured projects with **real board photos**, each opening a case study with a specs table, schematic/PCB images and a debugging story.
4. **Action:** a working CV download plus email and LinkedIn.

Design principles:

- One accent colour on a neutral dark or light base.
- Engineering visual language (a faint grid or PCB-trace motif, mono spec labels).
- Two font families.
- Consistent spacing tokens.
- WCAG AA contrast in both themes.
- Lighthouse ≥ 95 in every category.

### Phase 3 — Design system & visual refresh

**Scope:** D1, D2, D4–D7. Replace the template look with an engineering identity.

**Design spec:**

| Token | Value |
|---|---|
| Background (dark) | near-black neutral, e.g. `#0B0D10`; surface `#12151A`; border `#1F242C` |
| Background (light) | `#FAFAF7`; surface `#FFFFFF`; border `#E4E4DF` |
| Accent (one only) | pick one: copper `#D9822B` · signal cyan `#2BB3C0` · solder-mask green `#3FA34D` |
| Status colours | completed = green, in-progress = amber, prototype = blue. Used **only** in badges. |
| Fonts | Body/headings: **Inter** or **IBM Plex Sans** · Labels/specs/tags: **JetBrains Mono**. Remove Rubik and Mr Dafoe. Self-host via `@fontsource`. |
| Type scale | 14 / 16 / 18 / 22 / 28 / 40 / 56 px, line-height 1.5 body, 1.15 headings |
| Spacing | 4-px base: 4, 8, 12, 16, 24, 32, 48, 64, 96 |
| Radius | 6 px (cards), 999 px (chips) |
| Content width | max 1120 px |
| Background motif | faint 24-px grid or PCB-trace SVG at ≤6 % opacity. No wavy lines, no glows. |
| Motion | 150–250 ms fades and lifts. All disabled under `prefers-reduced-motion`. |

**Component changes:**

5. **Tokens:** put all of them in `src/styles/tokens.css`. No hard-coded colours or spacing in components.
