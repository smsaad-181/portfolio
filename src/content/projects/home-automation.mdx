## Objective

These boards bring Wi-Fi and wall-switch control to household mains loads such as lights, fans and sockets. Each one is a through-hole PCB built around an ESP32 module that runs a self-hosted web server, so it needs no cloud service, smartphone app or subscription: only the local Wi-Fi network and a browser.

The design exists in three revisions: a 4-channel board (V1) and two 6-channel boards (V2.1 and V2.2). All three share the same core: an onboard AC-DC supply, an isolated relay drive per channel, physical switch inputs and USB-C programming.

## Features

- 4 or 6 independent relay channels, driven active-high (GPIO HIGH turns the relay on).
- Each channel combines a PC817C optocoupler, a 2N2222A driver, a 1N4007 flyback diode and a status LED.
- Onboard Hi-Link AC-DC module powers the board straight from 220 V mains, with no external adapter.
- One physical wall-switch input per relay; firmware debounces each input over 50 ms.
- Self-hosted web dashboard on port 80 with a card-based UI that refreshes every 3 s.
- Per-relay custom names, daily ON/OFF schedules synced over NTP and a countdown auto-off timer.
- Per-relay statistics (trigger count, total ON time, last ON/OFF) and a 10-entry event log, all stored in ESP32 NVS flash.
- Master All-ON, All-OFF and Restart controls, plus a KPI row showing relays on, device IP, Wi-Fi RSSI and uptime.
- Wi-Fi credentials entered once over the serial monitor and saved to NVS; static IP by default with DHCP fallback.
- MOV surge suppression on the mains input and ESD protection on USB (V1 and V2.2).

## Hardware Design

### Power

Mains (220 V AC) enters through a screw terminal and feeds an onboard Hi-Link AC-DC module that produces 5 V for the relay coils. An AMS1117-3.3 LDO derives the 3.3 V rail for the ESP32, the logic side of the optocouplers and the CH340C. V1 and V2.2 use the HLK-10M05T module and add a 14D121K varistor across the input; V2.1 uses the HLK-PM01 and has no varistor in its BOM.

### Relay channels

Every channel uses the same isolated drive path: an ESP32 GPIO, a PC817C optocoupler that separates the 3.3 V logic from the relay-coil side, a 2N2222A transistor that switches the coil, and a 1N4007 flyback diode that clamps back-EMF when the coil turns off. A per-channel LED shows the relay state.

### Wall-switch inputs

On V1 the four switch inputs use GPIO 36, 39, 34 and 35. These are input-only pins with no internal pull-up, so the board fits 10 kΩ pull-ups (R27–R30) to 3.3 V. On V2.1 the six inputs use GPIO 33, 32, 35, 34, 14 and 15: GPIO 34 and 35 get external 10 kΩ pull-ups and the others use the ESP32's internal pull-ups. In the V2.1 firmware every debounced change of a switch toggles its relay, so the wall switch and the dashboard can share control of a relay without fighting each other.

### Programming and expansion

USB-C connects through a CH340C USB-to-UART bridge, with BOOT (GPIO0) and RESET (EN) buttons for flash mode. Every revision also has a 4-pin UART TTL header (RX, TX, GND, 3V3) and an I²C header on IO21/IO22. V1 adds a spare-GPIO header (IO25–IO27), and V2.1 adds a 6-pin SPI header (IO27, IO18, IO19, IO23, GND, 3V3).

## Outcome

Each revision has a complete fabrication package in its project folder: schematic PDF, editable EasyEDA Pro project, Gerber files, BOM with a pricing sheet, pick-and-place file and a 3D STEP model. V1 and V2.2 also include a GPIO pinout PDF, and V2.1 a pinout document.

Firmware is written for the Arduino ESP32 core using only built-in libraries (WiFi, WebServer, Preferences, time). V1 has a 4-channel sketch with wall-switch support. V2.1 has two 6-channel sketches: a dashboard-only version and a full version with wall switches. No firmware is in the V2.2 folder yet; its documentation points to the pinout PDF for the GPIO mapping.

Documented limitations: on V2.1, relay 5 is driven from GPIO12, an ESP32 strapping pin that may interfere with boot if the line idles HIGH, and the documentation recommends swapping it if unstable. The V1 documentation states the design is for prototyping and has not received CE, UL or equivalent certification, and that the varistor does not replace proper earthing or upstream surge protection.
